# 번역 스타일 가이드 (캐릭터별)

[English](TRANSLATION_STYLE.md)

이 가이드는 **한국어 번역**용입니다. 모든 언어에 공통인 캐릭터 성격과, 임시 번역 언어팩에서 사용한 표기 목록은 [영문판](TRANSLATION_STYLE.md)의 "Every language"를 참고하세요.

대사 번역에서 가장 중요한 것은 **캐릭터별 말투 일관성**입니다. 말투가 흔들리면 번역 품질이 떨어집니다. 행을 추가하거나 수정할 때 이 가이드를 따라 주세요.

## 등장 캐릭터와 말투

### 코볼트 (주인공, 세신사)
- 밝고 친근한 접객 말투. 기본은 해요체(예: "~해요", "~드릴게요")로 유지합니다.
- 추임새 `Yip!`은 한국어팩에서 **"삐익!"**으로 통일합니다. 의미 보충 `Yip! (Yes)`는 **"삐익! (네)"**처럼 괄호 설명을 유지해 번역합니다.
- 손님을 맞이하고 배웅하는 역할이므로 "문 열어 드릴게요"처럼 살피는 뉘앙스를 살립니다.

### 콘래드 (작은 붉은 드래곤)
- **거칠고 성급한 반말**. 짧고 강한 문장, 직설적인 어휘를 사용합니다.
- `Hell yeah` 같은 감탄은 맥락에 맞춰 의역합니다(예: "좋지", "최고다", "끝내주네" 등. 경우에 따라 약간의 욕설).
- 입은 거칠지만 속은 여리고, 연애 장면에서는 약간 서툰 느낌을 남깁니다.

### 라이언 (작은 드레이크)
- **부드럽고 친근한 반말**. 다정하고 조금 수줍은 말투를 유지합니다.
- 성적인 농담엔 부끄러워하면서도 흐름에는 잘 맞춰 들어갑니다.

### 알렉산더 (교수, 라벤더색)
- **학술적이고 점잖은 격식체**. 한국어팩 기준으로 하십시오체/격식 높은 해요체를 유지합니다.
- 어휘는 딱딱하고 품위 있게 선택합니다.
- 평판, 명예, 두관(crest)에 대한 집착을 드러내고, 과장된 품격을 유지합니다.

### 기타
- 맥스(코볼트 지인, 다혈질), 이그윅스(알렉산더 동료 교수)는 등장 비중이 낮습니다.

## "인간" 뉘앙스 피하기

이 세계에는 인간이 없습니다(드래곤, 코볼트, 그리폰 등). 영어 people / someone / folks / guy를 "사람"으로 고정 번역하면 전원이 인간처럼 들릴 수 있으므로, 맥락에 맞게 명사를 바꿔 주세요.

- someone / new people -> "누군가", "새로운 상대", "새로운 인연"
- folks / those around me -> "다들", "주변 이들", "상대"
- big guy / little guy(호칭) -> "큰 친구", "작은 친구" 또는 상황별 호칭
- you two(코볼트+드래곤 조합) -> "두 분", "너희 둘"
- 전원이 드래곤일 때는 말장난으로 "한 마리", "두 마리" 같은 처리도 가능
- 연인, 유명인, 개인적, 본인, 인생처럼 관용적으로 굳은 단어는 문맥상 허용

## 여러 캐릭터가 공유하는 대사

`speaker` 열에 여러 캐릭터가 함께 적힌 행(예: `Ryan/Alexander`)의 번역은 해당 캐릭터 모두에게 공통 적용됩니다. 먼저 모두에게 어색하지 않은 중립 표현을 고르세요.

도저히 하나로 맞추기 어렵다면, 공용 행은 등장 빈도가 높은 캐릭터 기준으로 번역하고 나머지는 대사 ID 행으로 분리해 조정하세요([CONTRIBUTING.ja.md](../CONTRIBUTING.ja.md#複数のキャラが話す台詞) 참고).

## 서식 태그

`<size=70%>` / `<gradient="gold">` / `<i>` / `<b>` 같은 TMP 태그는 **구조를 그대로 유지**하고, 내부 텍스트만 번역하세요. 괄호형 선택지 힌트(`(Will lead to no romance!)` 등)도 번역합니다.

## 이름 표기

- Conrad -> 콘래드
- Ryan -> 라이언
- Alexander -> 알렉산더
- Igwyx -> 이그윅스
- Max -> 맥스

대사에 `Conrad: ...`처럼 이름 접두사가 붙는 경우 `콘래드: ...`처럼 유지합니다.

## 번역 제외 (Yarn 내부 마커)

`title:` 행, `Test line` 행, 플래그(`player hooked up with ...` 등), 개발용 메시지, `---` / `===`는 표시 텍스트가 아니므로 번역하지 않습니다(`Translations/ignore.txt`에서 제외됨).
